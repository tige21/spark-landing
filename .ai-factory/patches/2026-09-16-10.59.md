# Кнопки CTA расходились по ширине: каждая ужималась по своей подписи

**Date:** 2026-09-16 11:00
**Files:** src/components/ui/PlayCTA.tsx, src/components/hero/HeroScroll.css, src/components/sections/FinalCta.astro, tests/smoke.spec.ts
**Severity:** medium

## Problem

На мобильном две кнопки входа в игру стоят друг под другом и заметно разной
ширины. Замер на 421×950:

```
hero  : 256 / 273  (разница 17px, левые края разъехались на 8px)
final : 294 / 313  (разница 19px, левые края на 9px)
```

## Root Cause

Кнопки были flex-элементами с `display: inline-flex` и `white-space: nowrap`,
то есть каждая получала ширину собственной подписи. «Открыть в Telegram» на
17–19px длиннее, чем «Играть в браузере».

Бок о бок на десктопе разница не читалась, поэтому проверка, добавленная при
вводе второй кнопки, её пропустила: тест сравнивал фон, цвет, рамку, радиус,
тень, кегль и padding — **но не геометрию**. Стопкой на телефоне те же 17px
выглядят как ошибка вёрстки.

## Solution

Контейнеры переведены с flex на grid с равными колонками:

```css
display: grid;
grid-auto-flow: column;   /* row в @media (max-width: 760px) */
grid-auto-columns: 1fr;
```

Плюс `justify-content: center` в самой кнопке — когда коробка шире текста,
иконка с подписью встают по центру, а не прижимаются к краю.

**Подводный камень, на который я сам наступил:** `1fr` — это
`minmax(auto, 1fr)`, а `auto`-минимум при `nowrap` равен ширине подписи. Я
поставил `.final .cta { max-width: 560px }`, а паре нужно 294+313+24 = 631px —
колонки не влезли и **молча** откатились к размеру по содержимому, вернув
исходные 294/313. Ограничение снято.

Замер после:

```
мобильный 421px : hero 373/373, final 389/389, левые края совпадают
десктоп  1512px : hero 277/277, final 350/350
```

## Prevention

- **«Одинаковые кнопки» — это и геометрия тоже.** Сравнение вычисленных стилей
  проходит при разной ширине: ширина не свойство, а результат раскладки. В
  тест добавлены `width` и `height` (но не `x` — бок о бок они законно разные).
- **`1fr` не гарантирует равные колонки при `nowrap`.** Если контейнер уже,
  чем сумма минимумов, grid тихо отдаёт каждой колонке её содержимое, и
  раскладка выглядит так, будто правила нет. Проверять, что контейнер шире
  суммы `max-content` всех колонок плюс gap.
- **Не ставить `max-width` на grid-контейнер с колонками по содержимому**, не
  посчитав эту сумму. Магическое число тут ломается молча и при первом же
  удлинении подписи или переводе.
- **Замерять после того, как въезд доиграл.** `.final` приезжает внутри
  `.reveal-tilt` с `perspective + rotateX`: во время анимации две кнопки
  проецируются в разный размер (379×65 против 383×67), и тест ловил артефакт
  анимации, а не вёрстку.
