# На мобильном телефон уезжал за верх экрана на второй способности

**Date:** 2026-09-16 01:05
**Files:** src/components/sections/ThroughPhone.css, tests/layout.spec.ts
**Severity:** high

## Problem

На телефоне во втором из трёх блоков секции ThroughPhone (способность «Игра»,
где показываются свайпы карточек) макет телефона уезжал за верхний край экрана.
Первый и третий блоки отображались нормально.

Замер на вьюпорте 421×950, обход по всем 13 шагам:

```
шаг 0-2  «Колоды»      data-side=right   phoneTop  123
шаг 3-6  «Игра»        data-side=left    phoneTop -166   ← за экраном
шаг 7-12 «Своя колода» data-side=right   phoneTop  123
```

Разница ровно 289px = 578/2, половина высоты телефона.

## Root Cause

Десктоп центрирует телефон по вертикали парой `top: 50%` + `-50%` внутри
`transform`:

```css
.tp-phone            { top: 50%; transform: translate(calc(-50% + var(--tp-dx)), -50%); }
[data-side='left'] .tp-phone { transform: translate(calc(-50% - var(--tp-dx)), -50%); }
```

Мобильный макет якорит телефон по ВЕРХУ и переопределяет transform, убирая
вертикальную часть:

```css
@media (max-width: 860px) {
  .tp-phone { top: var(--phone-top); transform: translateX(-50%); }
}
```

Переопределён только `.tp-phone` — специфичность (0,1,0). Правило
`[data-side='left'] .tp-phone` — (0,2,0) — продолжает выигрывать и возвращает
`-50%` по вертикали. `--tp-dx` на мобильном равен `0px`, поэтому горизонтально
разницы нет, а вертикально телефон подпрыгивает на половину своей высоты.

`data-side` вычисляется как `activeFeat % 2 === 0 ? 'right' : 'left'` — то есть
`left` выпадает ровно на вторую способность. Отсюда «ломается только второй
блок».

Дефект существовал с момента появления мобильного макета: в том же media-блоке
`[data-side='left']` был дописан к `.tp-phone` для свойства `transition`, но
для `transform` — нет.

## Solution

Мобильное правило переписано на обе цели:

```css
.tp-phone,
[data-side='left'] .tp-phone { top: var(--phone-top); transform: translateX(-50%); ... }
```

После: все 13 шагов дают `phoneTop: 123`, одно значение на всю секцию, разрыв
до подписи константный 8px, за экран ничего не уходит.

## Prevention

- **Переопределяя правило под медиазапрос, перечисли ВСЕ селекторы, которые его
  задают.** Медиазапрос не добавляет специфичности: `.tp-phone` внутри `@media`
  проигрывает `[data-side='left'] .tp-phone` снаружи. Искать по свойству
  (`grep 'transform' в файле`), а не по одному селектору.
- **Пара «top + translate(-50%)» неразделима.** Если другой контекст меняет
  якорь (`top: 50%` → `top: <px>`), вертикальную половину transform обязан
  снять КАЖДЫЙ селектор, который его выставляет. Это второй случай того же
  класса в этом файле за сессию — первым был `.tp-track`, где `position: static`
  в fallback не снимал `translateX(-50%)`.
- **Баг, зависящий от чётности индекса, проявляется только на части состояний.**
  «Ломается второй блок из трёх» — это подсказка искать `% 2` в коде, а не
  особенность контента. Тест обязан пройти ВСЕ состояния и проверить, что оба
  значения `data-side` реально встретились.
- **Мобильные проверки нельзя скипать целиком.** Соседние layout-тесты
  помечены `test.skip(project !== 'desktop')`, поэтому мобильный макет этой
  секции не был покрыт ничем.
