## Фидбек пользователей (дословно по сути)
- Можно проскроллить весь телефон **за два движения** — нет момента «остановись и пойми».
- **Текст не видно**, и **как он меняется — тоже не видно**. Нужно сильно ярче, акцентнее.
- Итоговая цель: **когда пользователь проскроллил весь телефон — он уже понял, как работает приложение.** Сейчас слишком быстро и непонятно, что происходит.

## Диагноз (из кода)
1. **Нет принудительной остановки на мобиле.** Wheel-step чинит ПК, но на телефоне Lenis ВЫКЛЮЧЕН (`SmoothScroll.tsx:21`) → нативная инерция проносит сквозь фазы; snap-on-idle ловит только когда инерция уже умерла (часто на 3-й фазе).
2. **Телефон статичен в покое.** Даже при остановке виден один замёрзший кадр — пользователь не ВИДИТ, как пользоваться приложением.
3. **Копия тусклая и мелкая** (`--meta`, 0.78–0.88rem), смена между фазами незаметна.

## Решение (подтверждено пользователем)
Превратить секцию в **управляемое демо**: дискретные блоки, переход — жест (свайп/колесо), на каждом блоке телефон **сам проигрывает сценарий**, копия — яркая, акцентная, с заметной анимацией входа, + индикатор шага.

- **Q1 (выбор):** телефон на каждом блоке **АВТОПРОИГРЫВАЕТ** сценарий (листает карты / открывает колоду / генерит). 
- **Q2 (выбор):** на мобиле — **жёстко: один свайп = один блок** (перехват тача), на краях секции свайп свободно выпускает дальше.

## Контекст файлов
- `ThroughPhone.tsx`: pinned sticky-stage; `apply()` f=p*n, плато панелей/canvas, phone X-slide (десктоп), derived per-segment `localP`→CanvasSequence; есть idle-snap (всё) + wheel-step (десктоп). Добавлены `getLenis()` (десктоп) для программного скролла.
- `CanvasSequence.tsx`: rAF-tick, читает `progress.get()`, eased index, `drawNearest` (graceful), lazy frames (active±1), defer-batch за `load`. **Шарится с hero** — autoplay делать opt-in (default off), hero не трогать.
- `ThroughPhone.css`: мобайл — `.tp-track` геом-переменные, телефон сверху / копия плотно под ним (центрированная пара); копия компактная и тусклая.
- `lib/smooth-scroll.ts`: `getLenis()/setLenis()`. Lenis только на десктопе.
- токены: `--space-*` (4/8/12/16/24), акцент — цвет кнопки «Играть» (винный) — найти токен в `tokens.css`.

## Открытые вопросы / риски
1. **Touch-перехват** не должен «запирать»: жёсткие условия выхода на краях обязательны; финальная проверка свайпа на реальном телефоне желательна (Playwright тач эмулирует ограниченно).
2. **Autoplay в shared CanvasSequence** — строго opt-in, hero и любой другой инстанс без props ведут себя как раньше. Проверить hero после правки.
3. Кадры активного блока должны успеть декодироваться к моменту autoplay (defer-batch за `load`); `drawNearest` даёт graceful, но первый вход может быть чуть рваным — допустимо.
4. Баланс «держать достаточно» vs «не застрял»: кулдаун/длительность — настраиваются в GD-5, перепроверка визуала обязательна.
5. Один проигрыш на входе + удержание последнего кадра (без бесконечного цикла) — меньше отвлекает; цикл можно добавить позже, если «оживить» покажется нужным.
