## Замеры «до» (эталон для приёмки)

Dev-сервер `npm run dev`, замер `document.body.scrollHeight` после полной гидратации.

| Блок | Десктоп 1440×900 | Мобильный 390×844 |
|---|---|---|
| hero | 2700 | 2026 |
| what | 490 | 748 |
| how | 432 | 1082 |
| **through-phone** | **9090** | **9841** |
| decks | 1130 | 2711 |
| premium | 432 | 637 |
| final | 606 | 551 |
| **вся страница** | **15537 (17,3 экрана)** | **18306 (21,7 экрана)** |

Формула высоты пина: `(1 + A * perAction) * 100svh`, где `A` — сумма `actions` по сегментам в `ru.json` (сейчас 3+4+6=13), `perAction = small ? 0.82 : 0.7` (`ThroughPhone.tsx:119`). Кадры скраба привязаны к прогрессу внутри сегмента (`useFeatureProgress`), а не к числу actions — уменьшение actions укорачивает скролл, но не выбрасывает кадры.
