## Запрос пользователя
- Сейчас одним большим скроллом можно пролистать весь телефон (особенно бланк заказа — 5 шагов пролетают в одно движение).
- Хотим: **один свайп пальцем = ровно одно действие**; нельзя проскочить — пользователь вынужден пролистать ВСЕ экраны.
- Каждое действие внутри бланка (и в остальных фичах) = один свайп.
- **Рефрейм:** это не «шаги» (последовательность того, что должен сделать юзер), а **возможности/бизнес-логика приложения**. Эйбрау = имя функции, без «Шаг N».

## Решения (выбор пользователя)
- Подпись блока = **имя функции** («Колоды» / «Игра» / «Своя колода»), без «Шаг N».
- Гранулярность: **~12 действий** — Колоды 3 · Игра 4 · Своя колода 5 (форсит пройти всё, но не изматывает).

## Контекст (из кода/кадров)
- Кадры: decks 36 (непрерывный скролл списка), play 52 (свайпы карт), **create 7 — НЕПОЛНЫЙ** (intro + шаги 1–4 из 5, без шага 5 и результата). create показывает реальный визард «ПУНКТ N ИЗ 5» (Кому/Тон/Тираж…). → create надо переснять.
- ThroughPhone сейчас: 3 сегмента, 1 snap-stop на сегмент; per-segment scrub; mobile CSS scroll-snap (proximity + snap-stop:always, 3 маркера); desktop wheel-step к центрам сегментов; idle-snap (десктоп); автоплей сценария на блоке.
- Модель «один свайп = одно действие» = обобщение текущей: вместо 3 стопов — **A стопов (по действию)**, scrub проигрывает действие между стопами при свайпе (автоплей больше не нужен).

## Модель действий
- Фичи: decks(3), play(4), create(5) → **A=12** действий, плоский список.
- decks/play — непрерывные кадры: прогресс фичи `featP = clamp01((fa-featStart)/featCount)` гонит CanvasSequence по всему набору; снап-стопы на равных позициях фичи.
- create — переснятые ~5–6 кадров (по экрану на действие): featP ≈ 1 кадр/действие.
- Скролл: `fa = p*A`; `ai=floor(fa)`; activeFeature = фича, содержащая ai. Видна только активная фича (дискретный кроссфейд по activeFeature). Телефон-side-slide (десктоп) на границах фич.
- Высота секции `(1 + A*perAction)*100svh`, `perAction≈0.75–0.8` (тюнинг в AC-6). Снап-маркеры на `top: calc((i+0.5)*perAction*100svh)` для i∈0..A-1.
